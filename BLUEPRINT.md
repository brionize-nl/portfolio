# Portfolio — Blueprint

## Doel
Persoonlijke portfolio website voor Brionize.
Gebouwd als test van DELPHI als development platform.

## Tech stack
- Vanilla HTML/CSS/JS (geen frameworks)
- Gehost via GitHub Pages
- Dark theme, responsive

## Pagina's
1. **Home** — intro + headline
2. **Projecten** — overzicht van repos (DELPHI, Brionicle, SysDash)
3. **Over** — korte bio
4. **Contact** — links (GitHub, email)

## Stijl
- Minimalistisch, donker thema
- Mobiel-first design
- Snelle laadtijd, geen externe dependencies
